# CortexTrace
A high-performance, real-time 32-channel EEG viewer &amp; DSP analyzer built with Python, PySide6, and pyqtgraph. Features wall-clock playback pacing, zero-allocation ring buffering, digital Butterworth &amp; notch filters, Density Spectral Array (DSA), and cross-platform hardware auto-tuning (Windows, Linux, Raspberry Pi).
